dxinfer · OrtMode::Auto (default)

Auto ORT: the right setting for every compiled model

After compiling, a model can have CPU parts that run on ONNX Runtime (ORT). With ORT off, dx-runtime runs only the first NPU part, and nothing reports it. Auto mode reads the model and decides for the user.
